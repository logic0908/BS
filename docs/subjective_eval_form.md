# Subjective Evaluation Form

本表用于答辩前后的主观试听记录，建议至少由 3 名听评人独立填写。

## Scoring Guide

- 风格符合度：提示词目标风格是否明显体现
- 自然度：是否存在明显失真、机械感、断裂感
- 歌词可懂度：歌词/发音是否清晰可辨
- 原旋律保持：原旋律与节奏是否基本保持
- 总体满意度：综合主观体验

评分建议：`1-5`

- `1` 很差
- `2` 较差
- `3` 一般
- `4` 较好
- `5` 很好
