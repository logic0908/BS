# Demo Screenshot Guide

答辩和论文建议至少补齐以下截图（当前前端已完成“布局压缩 + 术语中文化”）：

1. 首页 / 正式演示工作台
2. 系统状态区：真实 SVC、GPU 可见、Internal FiLM
3. 上传音频后的输入质量提示
4. 文本 prompt 输入区
5. 高级转换参数区
6. 转换中任务进度
7. 转换结果卡片（单输出播放器 + 下载）
8. 关键指标对比表（输入/输出/变化）
9. 技术链路展示（中文主字段）
10. 模型缺失或依赖缺失错误提示示例

截图建议同时保留：

- 时间戳
- prompt 文本
- 模型预设信息
- 目标音色信息（如 `lain`）
- 若 prompt 包含“男声”但目标音色未切换，保留对应 warning 截图
- 若存在 fallback，则显式展示 warning

补充说明：

- 主页面已删除“转换前后音频对比”大卡片，避免重复播放器占用空间。
- 主页面字段统一中文，英文原字段仅保留在折叠的“字段说明”中。
- 转换结果卡片内新增“频谱图对比”（紧凑双列/窄屏单列），展示上传音频与转换后音频的频率/能量分布可视化差异。
- 频谱图属于前端可视化辅助展示，不作为主观听感结论依据。
