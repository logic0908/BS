# Demo Screenshot Guide

答辩和论文建议至少补齐以下截图：

1. 首页 / 正式演示工作台
2. 系统状态区：真实 SVC、GPU 可见、Internal FiLM
3. 上传音频后的输入质量提示
4. 文本 prompt 输入区
5. 高级转换参数区
6. 转换中任务进度
7. 转换结果 A/B 波形对比
8. `condition_mode / film_strength / executed_internal_film` 元数据展示
9. 风格证据分析面板
10. 模型缺失或依赖缺失错误提示示例

截图建议同时保留：

- 时间戳
- prompt 文本
- preset 信息
- condition mode
- 若存在 fallback，则显式展示 warning
